# Python Backend Trainer v2

## Что внутри
| Папка / файл | Что это |
|---|---|
| `app.py`, `sandbox.py`, `tasks.py` | Запуск, песочница проверки кода, загрузчик задач |
| `ui/` + `vendor/` | Интерфейс (HTML/CSS/JS) и редактор CodeMirror; `app.py` склеивает их в одну страницу |
| `data/tasks/*.json` | 39 задач: условие, шпаргалка, подсказки, тесты. Правятся руками |
| `data/kb/*.kb` | База знаний помощницы (269 карточек) |
| `assistant/` | «Мозг» помощницы: поиск, разбор кода и ошибок, контекст, манера речи |
| `assets/chibi/` | Усиленные SVG-персонажи; `assets/chibi_original/` исходные файлы |
| `tools/boost_breathing.py` | Делает дыхание заметнее (инструкция в `assets/chibi/README.txt`) |
| `tests/` | Проверки базы и качества помощницы |

## Запуск и сборка
    pip install -r requirements.txt
    python app.py                 # обычный запуск
    python app.py --selftest      # проверка без окна (ресурсы, помощница, песочница)
    pyinstaller --noconfirm Trainer.spec
    dist\Trainer.exe --selftest   # то же самое для собранного exe

Если запуск падает на старте, причина записывается в `crash.log` рядом с базой прогресса.
`console=True` в `Trainer.spec` оставлен на время проверки; для выкладки поставь `False`.

## Как добавить задачу
Добавь объект в `data/tasks/<категория>.json` (формат описан в начале `tasks.py`). Типы: `stdout`, `function`, `fastapi` (можно несколько запросов в `checks`), `quiz`. Многострочные поля (`template`, `cheat`, `code`) это списки строк.

## Как расширить помощницу
Карточка в `data/kb/*.kb`:

    @ id | тема | Заголовок
    ? фраза вопроса; ещё фраза; ещё одна      # живые формулировки, чем больше, тем лучше
    # теги слова для поиска
    = Короткий ответ (первый абзац показывается сразу).
    = Дополнительные абзацы (в режиме «Подробнее»).
    > строки примера кода
    ! частая ошибка
    + совет
    ~ id-связанной-карточки
    en: короткий ответ по-английски (необязательно)

Добавить формулировки к готовой карточке, не трогая её: `@+ id` и строка `? ...`.
Всё, что помощница не смогла ответить, пишется в `unanswered.txt` (папка данных приложения): это готовый список, что дописывать в базу.

## Проверки
    python tests/check_kb_examples.py   # все примеры кода в базе должны выполняться
    python tests/assistant_eval.py      # регрессия поиска (набор подогнан, нужен для контроля)
    python tests/assistant_blind2.py    # слепой набор: честное качество на незнакомых вопросах

## Повторение
Решённая задача ставится в график: через 1, 3, 7, 14, 30 дней. Чистое повторение двигает задачу дальше по лесенке, ошибка возвращает на 1 день. Повторение идёт с пустой заготовки и свёрнутой шпаргалкой.
