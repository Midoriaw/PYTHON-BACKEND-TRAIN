Чиби-персонажи. Приложение показывает их как обычную <img>: меняется только файл (src) и ширина,
высота считается автоматически. Само приложение ничего не анимирует. Дыхание ведёт сам SVG.

ВАЖНО: файлы в этой папке это усиленные копии. Исходные SVG лежат нетронутыми в assets/chibi_original/.
Усиленная версия получается командой (из корня проекта):
    python tools/boost_breathing.py assets/chibi_original/goth.svg assets/chibi/goth.svg --k 1.0
    --k 1.0 нормально, 1.4 заметнее, 0.7 мягче. Скрипт описывает, что именно меняется.

Добавить нового персонажа:
  1. Положи name.svg в assets/chibi_original/ (если дыхание в нём уже нормальное, можно сразу в assets/chibi/).
  2. Для усиления добавь строку name в PRESETS в tools/boost_breathing.py (cx, keys, lift, sx), запусти команду.
  3. Он сам появится в списке Character. Реестр в коде не нужен.
